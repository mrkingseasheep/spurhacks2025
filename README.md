# CampSwipe Spurhacks2025 Project

This is our project for SpurHacks 2025. Our campsite data is scraped with python from Parks Canada and stored with MongoDB. Users have the ability to create a group and select their likes and dislikes in a campsite. Campswipe then recommends campsites from our database that best matches everyone's preferences. Users then swipe left or right to vote on their favourite campsites creating an interactive way to plan a camping trip.
